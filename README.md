 2-DOF Robotic Arm Simulation

Developed a planar 2-DOF robotic arm model in MATLAB Simscape Multibody to study manipulator kinematics and motion behavior.

- Performed forward kinematic analysis using coordinate transformations.
- Computed end-effector position and orientation using `getTransform()`.
- Generated trajectory and workspace plots for motion analysis.
- Visualized and validated robotic arm movement through simulation.

**Tools:** MATLAB, Simscape Multibody, Simulink
